## What is GitHub Pages?

**GitHub Pages** is a service provided by GitHub that allows users to host static websites directly from a GitHub repository.

The website in this assignment is created using **Markdown** rather than writing HTML manually.

### Technologies

| Technology | Purpose |
|---|---|
| GitHub | Version control and code hosting |
| GitHub Pages | Website hosting |
| Markdown | Creating the website content |
| Jekyll | Processing Markdown into a website |
